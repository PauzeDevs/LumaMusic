Project technology

  • Expo and React Native for the application runtime.
  • Expo Audio is configured as the app's native audio-engine layer; current YouTube Music playback is handed off to the official app or website.
  • Expo Router for navigation.
  • TanStack Query for remote data state.
  • Zustand and AsyncStorage for local application state.
  • Google Fonts for the website's Manrope and DM Mono typefaces.
